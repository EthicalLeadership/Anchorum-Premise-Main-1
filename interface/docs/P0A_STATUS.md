**Shell wiring correction:** during the earlier verification pass, shell chrome (case header, rail, and drawer) was absent on all case-scoped routes because `App.tsx` passed `case={null}` unconditionally. This is fixed: the app now loads the route's case before rendering the shell and passes it to `AppShell`; case screens continue to load their own data. The rail's `/overview` URL also now routes to the Overview screen. In this pass, Overview, Register, and Audit were re-opened at 1280px; each rendered its expected screen content alongside the case header and rail. The duplicate case fetch is known tech debt: post-P0-A, hoist the case load to App and pass it to both shell and screen.
